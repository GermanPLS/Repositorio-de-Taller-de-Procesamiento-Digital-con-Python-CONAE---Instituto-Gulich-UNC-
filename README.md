Repositorio personal de prácticas y desarrollos realizados durante el Taller: **Procesamiento Digital de Imágenes con Python - CONAE / Instituto Gulich**


### Link: https://ig.conae.unc.edu.ar/procesamiento-digital-con-python-2026/

---

## Objetivo

Este repositorio contiene notebooks, scripts y resultados relacionados con el procesamiento digital de imágenes satelitales utilizando Python.

Los principales objetivos son:

- Comprender la estructura digital de una imagen raster.
- Manipular imágenes mediante matrices utilizando Python.
- Aplicar técnicas de realce radiométrico.
- Generar composiciones RGB y falso color.
- Explorar herramientas para análisis de información satelital.
